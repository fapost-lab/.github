# .github

Organisation-wide defaults for [FaPost Lab](https://github.com/fapost-lab).

Nothing here is code. GitHub uses these files for every repository in the
organisation that does not carry its own copy, so there is one place to change a
policy rather than five that drift apart.

| | |
|---|---|
| [`profile/README.md`](profile/README.md) | The organisation's landing page at [github.com/fapost-lab](https://github.com/fapost-lab) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to propose a change |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | What is expected of participants, and how to report what is not |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help, and what to include when asking |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Issue forms and the links shown beside them |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | The pull request checklist |

A repository that needs to differ overrides a file by adding its own; the
default then no longer applies to it.

This repository must stay public for the defaults to take effect — including for
private repositories in the organisation. It contains no private information for
that reason.
